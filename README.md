# complexity
complexity is a esoteric programming language made with a python preprocessor.

it replaces the python syntax with the following, please do type with this syntax

1.functions
    "def" --> "WHAT"
    "return" --> "here"

2.conditionals
    "if" --> "this then"
    "elif" --> "if aint then"
    "else" --> "it aint then"

    "==" --> "is"
    "!=" --> "isnt"

3.loops
    "for" --> "spin round til"
    "while" --> "spin round while"

4.boolean
    "True" --> "deadass"
    "False" --> "cap"

5.print
    "print" --> "spitout"

the filename must be saved with the extention ".complex"

to execute the code, use the commandline
for linux:
    python3 complexity.py filename.complex

for windows:
    python complexity.py filename.complex

replace filename with the actual filename of your program.

make sure the complex.py and your code are in the same project file while executing, en example code has been included as "rando.complex".
feel free to not try out this lang.
